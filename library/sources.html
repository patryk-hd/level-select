Privacy and permissions: what Level Select reads, and what it asks for

Read on this computer, never changed

  • Steam: the list of accounts that signed in here (names and Steam IDs only; no passwords).
  • GOG Galaxy: its library database, read from a temporary copy.
  • ES-DE: its game lists, box art and settings.
  • ROM folders you choose (file names only) and Playnite exports you drop here.

Everything Level Select saves stays in library/data in its own folder.

Sent over the internet

  • Steam: your Steam ID (for the wishlist), your Web API key (for owned games), and game ids for prices and reviews.
  • IGDB, Wikidata and VideoGamesCritic: game titles and ids, to fetch scores, awards and time to beat.

Nothing else about you leaves this computer.

Permissions on a new computer

  • macOS: Steam, GOG Galaxy and ES-DE need no permission. If a ROM folder is on an external drive or in Desktop, Documents or Downloads, macOS asks once (“Level Select would like to access files…”): choose Allow. Changed your mind? System Settings → Privacy & Security → Files & Folders → Level Select (or Terminal, if you run npm run dev).
  • Windows and Linux: no prompts. GOG Galaxy’s database is readable without administrator rights.
  • Steam: the wishlist and owned games need your profile’s Game details set to Public. Owned games also need your Web API key (step 3).
